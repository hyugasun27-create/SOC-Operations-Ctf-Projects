# SOC Operations & CTF Projects

A hands-on cybersecurity portfolio documenting SOC operations, Capture The Flag (CTF) challenges, threat detection, incident response, malware analysis, and digital forensics.

## About This Repository

This repository showcases my practical journey toward becoming a SOC Analyst.

It contains investigation reports, technical findings, security event analysis, network investigations, and hands-on blue-team projects.

- Phishing and Malware Analysis

- SIEM Investigation

## Investigation Documentation

Each completed case report aims to include:

1. Incident overview
2. Investigation objectives
3. Evidence sources
4. Technical analysis
5. Indicators of Compromise (IoCs)
6. Attack timeline
7. MITRE ATT&CK mapping
8. Findings and conclusion
9. Containment and remediation recommendations
